# Doctor Top CPD — สตูดิโอโคลนเสียง

สตูดิโอภาษาไทยสำหรับ Doctor Top CPD: อัดเสียงของตัวเองและประโยคยินยอม → สร้างโปรไฟล์เสียง → พิมพ์บท → ฟังและดาวน์โหลด MP3/WAV ใช้ได้ผ่านคอมพิวเตอร์และมือถือ **เปิดเว็บแล้วใช้ได้เลย ไม่มีรหัสผ่าน**

- เว็บไซต์: `https://doctor-top-cpd.vercel.app` — URL เป้าหมาย ตรวจสถานะยืนยันใน [บันทึกการตรวจ](docs/VERIFICATION.md)
- Repository: [gobank01/doctor-top-cpd](https://github.com/gobank01/doctor-top-cpd)
- [คู่มือติดตั้งบน Vercel](docs/DEPLOY-VERCEL.md) · [Prompt พร้อมใช้](docs/PROMPTS.md) · [ข้อมูลและสิทธิ์การเข้าถึง](docs/SECURITY.md)

การติดตั้งนี้ใช้ Gemini API ของผู้ดูแลตามที่เจ้าของอนุญาต คีย์อยู่บน server เท่านั้น เพื่อนที่ใช้เว็บไซต์ไม่ต้องกรอกคีย์ ส่วนคนที่ clone repo ไปติดตั้งเองต้องตั้งคีย์และที่เก็บข้อมูลของตนเอง ไม่มีค่าลับหรือเสียงของเจ้าของติดมากับ repo

**เป็นสตูดิโอร่วมกัน:** ทุกคนที่เปิด URL สามารถใช้โควตาของบัญชีที่เชื่อม เห็นคลังเสียง ประวัติ และดาวน์โหลดไฟล์ในสตูดิโอนี้ได้ ไม่มีบัญชีแยกหรือโควตารายคน ใช้เฉพาะเสียงและบทที่เจ้าของยินยอมให้ผู้ใช้สตูดิโอร่วมกันเข้าถึง ไม่ใส่ข้อมูลผู้ป่วยหรือข้อมูลลับ

## ใช้งานครั้งแรก

1. เปิดเว็บไซต์ด้วย Safari บน iPhone หรือ Chrome บน Android/คอมพิวเตอร์ แล้วเลือก **เพิ่มเสียงใหม่**
2. อนุญาตไมโครโฟน อัด **เสียงตัวอย่าง 20–30 วินาที** พูดตามธรรมชาติในห้องเงียบ ฟังคลิปก่อนทำขั้นต่อไป หรือใช้ไฟล์ตัวอย่างที่อัดเองในขั้นนี้ได้
3. อัด **ประโยคยินยอม** สดตามข้อความบนจอให้ครบ ใช้คนเดียวกัน ไมค์เดียวกัน และห้องเดียวกัน ห้ามให้ AI อ่านแทน ประโยคนี้ไม่มีปุ่มอัปโหลดไฟล์
4. ตั้งชื่อเสียงที่จำได้ เลือก **Flash TTS** ติ๊กยืนยัน แล้วกด **บันทึกเสียงใหม่** ระบบส่งคลิปทั้งสองไป Google เพื่อสร้างโปรไฟล์เสียง
5. เปิด **สร้างเสียงพูด** เลือกเสียงของตัวเอง วางบทสั้น 1–3 ประโยค เลือกสไตล์ แล้วกด **สร้างเสียงพูด** ถ้าต้องการระบุอารมณ์เอง เลือก **สไตล์การพูด → กำหนดเอง**
6. กดเล่น ฟังตรวจชื่อเฉพาะ ตัวเลข คำอ่าน และจังหวะ แล้วดาวน์โหลด **MP3** หรือ **WAV** เก็บไว้

ผู้ใช้และเจ้าของเสียงต้องมีสิทธิ์ตามข้อกำหนดของบริการ ใช้เสียงผู้ใหญ่ที่ยินยอมจริง ผลลัพธ์เป็นเสียงสังเคราะห์และไม่รับประกันความเหมือน 100% แจ้งผู้ฟังตามบริบทว่าเป็นเสียง AI

### เมื่อใช้มือถือ

- เปิด **URL HTTPS** ของสตูดิโอโดยตรง หากเปิดจาก LINE/Facebook แล้วใช้ไมค์ไม่ได้ ให้เปิดต่อใน Safari/Chrome
- ระหว่างอัดให้เปิดหน้านี้ไว้ อย่าล็อกจอหรือสลับแอป ระบบจะหยุดอัดเมื่อถูกขัดจังหวะ แล้วต้องตรวจคลิปหรืออัดใหม่
- อนุญาตไมค์ทั้งในเบราว์เซอร์และการตั้งค่ามือถือ กด ▶ เพื่อฟัง เพราะมือถือไม่เล่นเสียงอัตโนมัติ
- `localhost` บนมือถือหมายถึงมือถือเอง ใช้ URL Vercel ไม่ใช่ `localhost:8787` ของคอมพิวเตอร์
- บทที่กำลังเขียนเก็บในแท็บ (`sessionStorage`) ปิดแท็บอาจหาย คัดลอกบทไว้ก่อน
- คลิปที่อัดค้างอยู่แยกตาม session ของเบราว์เซอร์ แต่เมื่อบันทึกเป็นเสียงหรือผลงานแล้วจะอยู่ในคลังร่วม

## ข้อมูลเก็บที่ไหน

| ข้อมูล | ที่เก็บ / ผู้ที่เข้าถึงผ่านแอป |
|---|---|
| คลิปตัวอย่าง ประโยคยินยอม MP3/WAV และ metadata บนเว็บ | private Vercel Blob **แยกของ Doctor Top CPD**; แอปให้ผู้เปิด URL เข้าถึงคลังและผลงานร่วมกัน |
| โปรไฟล์เสียงที่ Google สร้าง | Google project ของ Gemini API ที่ผู้ดูแลเชื่อม; ใช้สำหรับสร้างเสียงผ่าน Google |
| คีย์ API, Blob token, session secret | Environment Variables ฝั่ง server ของ Vercel ไม่อยู่ใน browser/Git |
| ฉบับร่างบทพูดและตัวเลือกที่ยังไม่ส่ง | sessionStorage ของแท็บนั้น |
| ข้อมูลโหมด local | `samples/`, `out/`, `voices.json` บนเครื่องที่รัน; mock แยกใน `_mock/` |

สตูดิโอนี้เริ่มด้วยคลังว่าง ไม่ย้ายเสียง ไฟล์ หรือประวัติจากสตูดิโอเดิม แม้ใช้ Gemini API เดียวกัน เว็บแสดงและใช้เฉพาะเสียงที่บันทึกในสตูดิโอนี้และเสียงมาตรฐานที่ระบบรองรับ ไม่เปิดรายการโปรไฟล์อื่นใน Google project

คำว่า **private Blob** หมายถึงไฟล์ต้นทางไม่เป็น public Blob URL ไม่ได้หมายความว่าผลงานในเว็บนี้เป็นความลับจากผู้ที่มี URL สตูดิโอ ดูขอบเขตเพิ่มเติมใน [SECURITY.md](docs/SECURITY.md)

## Requirement ทั้งหมด

**ผู้ใช้เว็บไซต์ที่ติดตั้งแล้ว:** เบราว์เซอร์ปัจจุบัน อินเทอร์เน็ต ไมโครโฟนพร้อมสิทธิ์ใช้ไมค์ และเสียงของตนเองพร้อมความยินยอม ไม่ต้องติดตั้ง Python ไม่ต้องมี GPU และไม่ต้องกรอก API key

**ผู้ติดตั้ง repo เอง:**

| สิ่งที่ต้องมี | ใช้ในเครื่อง | ขึ้น Vercel |
|---|---|---|
| macOS / Windows / Linux | ใช้ติดตั้งและรัน | ใช้เตรียม repo หรือ Vercel CLI |
| Python | 3.11+ แนะนำ 3.13 | 3.13 ตาม `.python-version` |
| Gemini API key และสิทธิ์โมเดล | ใส่ใน `.env` ของตนเอง | ใส่ Environment Variables ฝั่ง server |
| Billing / quota | ตรวจบัญชีผู้ให้บริการก่อนใช้จริง | เช่นเดียวกัน ค่าใช้จ่ายเป็นของบัญชีที่เชื่อม |
| FFmpeg | dependency `imageio-ffmpeg` ติดตั้งให้ หรือใช้ FFmpeg บน PATH | ติดตั้งจาก dependencies |
| Git / GitHub | ใช้ clone หรือ Download ZIP | ใช้ repo ของตนเองสำหรับ Import |
| Vercel และ private Blob | ไม่จำเป็น | project และ Blob ใหม่สำหรับ installation นี้ |
| `SESSION_SECRET` | ไม่จำเป็นสำหรับ local server | ต้องสร้างใหม่ ใช้ลงนาม session อัปโหลด ไม่ใช่รหัสล็อกอิน |
| HTTPS | `http://localhost` ใช้ไมค์บนเครื่องที่รันได้ | ต้องใช้ HTTPS เพื่อขอไมค์จากมือถือ |
| Node.js 20+ | เฉพาะ recorder tests หรือ Vercel CLI | ไม่ต้องมี build frontend |

Dependencies แบบตรึงเวอร์ชันอยู่ใน [requirements.txt](requirements.txt) และ [requirements-dev.txt](requirements-dev.txt) การสังเคราะห์เสียงทำผ่าน Gemini ไม่ฝึกโมเดลในเครื่อง พื้นที่ใช้งานขึ้นกับจำนวนและความยาวของไฟล์

## ติดตั้งและเปิดในเครื่อง

```bash
git clone https://github.com/gobank01/doctor-top-cpd.git
cd doctor-top-cpd
python3 scripts/setup.py
python3 run.py --mock --open
```

Windows ใช้ `py -3` แทน `python3` หรือดาวน์โหลด **Code → Download ZIP** แล้วเปิด PowerShell ในโฟลเดอร์ที่มี README ตัวติดตั้งสร้าง `.venv` ติดตั้ง dependencies และสร้าง `.env` ว่างจาก `.env.example` โดยไม่เขียนทับไฟล์เดิม

โหมด mock ไม่เรียก Gemini ข้อมูลอยู่ใน `_mock/` เสียงเป็นเสียงระบบ/เสียงโทนจำลอง ใช้ดูหน้าจอและตรวจการทำงาน **ใช้ตัดสินความเหมือนของเสียงไม่ได้**

ใช้จริงโดยใส่ `GEMINI_API_KEY` ใน `.env` ของเครื่องนี้อย่างเป็นส่วนตัว แล้วเปิด:

```bash
python3 run.py --open
```

เปิด [http://localhost:8787](http://localhost:8787) บนเครื่องเดียวกับที่รัน ถ้าพอร์ตไม่ว่าง ใช้ `--port 8788` และเปิดพอร์ตนั้น หยุดด้วย Ctrl+C ตัวเลือกอื่นคือ `bash run.sh --open` หรือ `powershell -File run.ps1 --open`

Integration นี้เรียก Google โดยตรง จึงใช้ Gemini API key; คีย์ OpenRouter ใช้แทนไม่ได้ อย่าวางคีย์ในแชต GitHub หรือ frontend ระบบ setup ไม่ดึงคีย์จากโปรเจกต์อื่นอัตโนมัติ

## ขอบเขตและค่าใช้จ่าย

- ไฟล์อัปโหลดสูงสุด 40 MB แปลงเสียงเป็น WAV 24 kHz mono 16-bit ก่อนตรวจ
- ตัวอย่างต้องยาว 10–30 วินาที แนะนำอัด 20–30 วินาที; ประโยคยินยอม 2–20 วินาที
- บทพูดสูงสุด 20,000 ตัวอักษร ระบบแบ่งท่อนแล้วต่อไฟล์ งานยาวอาจเกินเวลา cloud ควรเริ่มจากบทสั้น
- Flash TTS เป็นค่าเริ่มต้นสำหรับไทย ตรวจโมเดลและภาษาปัจจุบันที่ [Google speech generation](https://ai.google.dev/gemini-api/docs/speech-generation)
- ค่าสร้างเสียง โควตา Vercel และ Blob เป็นของบัญชีที่เชื่อม ตรวจ [Gemini pricing](https://ai.google.dev/gemini-api/docs/pricing) และ [Vercel pricing](https://vercel.com/pricing) ไม่มีคำรับประกันว่าใช้ฟรีตลอด
- คลิปและบทถูกส่งไปยังผู้ให้บริการตามขั้นตอน ตรวจการเปิด Billing และเงื่อนไขข้อมูลก่อนใช้เสียงส่วนตัวที่ [Gemini API terms](https://ai.google.dev/gemini-api/terms)
- การลบไฟล์ใน Blob/เครื่อง ไม่ได้ลบโปรไฟล์เสียงใน Google และการลบ deployment ไม่ได้ลบ Blob อัตโนมัติ

## ทดสอบโดยไม่ใช้ API จริง

```bash
python3 scripts/setup.py --dev
.venv/bin/python -m unittest discover -s tests -v
node --test tests/mobile-recorder.test.cjs
python3 scripts/check_release.py
```

Windows ใช้ `py -3` และ `.venv\Scripts\python.exe` แทนคำสั่ง Python ที่ตรงกัน เทสต์ใช้ mock provider, ไฟล์ชั่วคราวและ mock media APIs ไม่อัดไมค์จริงหรือสร้างเสียงแบบเสียเงิน ดูผลที่ยืนยันแล้วใน [VERIFICATION.md](docs/VERIFICATION.md)
