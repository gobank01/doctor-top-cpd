# Prompt พร้อมใช้กับ Doctor Top CPD

คัดลอกแต่ละก้อนไปใช้ได้ทันที ไม่ใส่ API key หรือข้อมูลลับลงแชต บทพูดวางใน **สร้างเสียงพูด**; คำสั่งอารมณ์แยกไป **สไตล์การพูด → กำหนดเอง**

## 1. ให้ AI ช่วยติดตั้ง repo ในเครื่อง

```text
ช่วยติดตั้ง Doctor Top CPD ในโฟลเดอร์โปรเจกต์นี้ อ่าน README.md และ AGENTS.md ก่อน ตรวจ Python, .venv และ FFmpeg ใช้ scripts/setup.py ติดตั้ง dependencies ตาม requirements.txt สร้าง .env จาก .env.example เฉพาะเมื่อยังไม่มี ห้ามดึงคีย์จากโปรเจกต์อื่นหรือแสดงค่าลับลงแชต เริ่มจาก run.py --mock เพื่อทดสอบหน้าจอโดยไม่ใช้ค่า API ตรวจหน้าเพิ่มเสียงใหม่และสร้างเสียงพูด แล้วสรุปคำสั่งเปิดจริง วิธีหยุด และสิ่งที่ยังต้องตั้งค่า สตูดิโอนี้ไม่มีรหัสผ่านและใช้คลังร่วม ห้ามอ้างว่า mock ยืนยันคุณภาพเสียงจริงหรือไมค์โทรศัพท์แล้ว
```

## 2. เขียนบทพากย์ภาษาไทย 1 นาที

```text
ช่วยเขียนบทพากย์ภาษาไทยประมาณ 1 นาที หัวข้อ “เริ่มใช้ AI ให้เป็นผู้ช่วยในการทำงานวันละนิด” สำหรับคนทำงานทั่วไป ใช้ภาษาพูดสุภาพ เป็นธรรมชาติ เปิดด้วยปัญหาที่คนทำงานเจอ ยกตัวอย่างที่ไม่อ้างตัวเลขหรือผลลัพธ์เกินจริง 3 ข้อ แล้วจบด้วยสิ่งเล็ก ๆ ที่ลองทำได้วันนี้ ส่งสองส่วน: บทพูดพร้อมวางในช่องบทของ Doctor Top CPD ไม่มีหัวข้อหรือคำสั่งที่ไม่ต้องการให้อ่าน และสไตล์ภาษาอังกฤษสั้น ๆ สำหรับ สไตล์การพูด → กำหนดเอง ให้เสียงอบอุ่น ไม่เร่ง ไม่รับประกันว่าอ่านตรง 60 วินาทีพอดี
```

## 3. บทอ่านสำหรับอัดเสียงต้นแบบ

```text
ช่วยเขียนบทภาษาไทยให้ฉันอ่านอัดเสียงต้นแบบของตัวเองประมาณ 20–30 วินาที เนื้อหาเรื่องชีวิตประจำวันแบบเป็นธรรมชาติ มีประโยคสั้นและยาวเล็กน้อย อ่านง่าย ไม่ใส่ข้อมูลส่วนตัวหรือข้อมูลผู้ป่วย ไม่เลียนแบบเสียงคนอื่น ไม่แต่งประโยคยินยอมใหม่ ส่งเฉพาะบทอ่าน ส่วนประโยคยินยอมฉันจะอ่านตามข้อความที่แสดงใน Doctor Top CPD แยกอีกคลิปด้วยเสียงของตัวเอง
```

## 4. ให้ AI ช่วย deploy สำเนาของตนเอง

```text
ช่วยนำ repo Doctor Top CPD นี้ขึ้น Vercel ของฉัน อ่าน docs/DEPLOY-VERCEL.md และ AGENTS.md ก่อน ตรวจว่าไม่มี .env คีย์จริง เสียงส่วนตัว ประวัติ หรือ .vercel ของคนอื่น ใช้ FastAPI app.py, Python 3.13, private Blob ใหม่และ maxDuration 300 วินาทีตาม config สร้าง SESSION_SECRET ใหม่ผ่าน scripts/create_session_secret.py เก็บ Gemini API key ที่ฉันอนุญาตกับ Blob token และ session secret ใน Environment Variables ฝั่ง server โดยไม่แสดงค่าในแชต เว็บนี้ไม่มีรหัสผ่าน ไม่ต้องสร้างหน้าล็อกอิน อธิบายให้ชัดว่าเสียงและประวัติเป็นคลังร่วม ตรวจว่าไม่ได้เปิดเผยโปรไฟล์อื่นใน Google project ตรวจ mock tests และ release checker ก่อน deploy แล้วตรวจ URL จริงและสถานะ Ready ห้ามสร้างเสียงจริงแบบเสียเงินเพื่อทดสอบจนกว่าฉันจะอนุญาต รายงานสิ่งที่ตรวจและสิ่งที่ยังไม่ทดสอบตามจริง
```

## 5. ตรวจบทก่อนสร้างเสียง

```text
ตรวจบทพูดที่ฉันจะส่งในข้อความถัดไปสำหรับเสียงโคลนของตัวเอง แก้ประโยคที่อ่านสะดุด แยกย่อหน้าให้หายใจง่าย เปลี่ยนตัวย่อหรือตัวเลขที่กำกวมเป็นคำอ่านตามบริบท รักษาความหมายเดิม ไม่เติมข้อมูลหรือคำกล่าวอ้างใหม่ ถ้าชื่อเฉพาะไม่แน่ใจ ให้อธิบายแยกจากบท ส่งบทพร้อมวางในช่องบทของ Doctor Top CPD หนึ่งชุด ไม่มีคำอธิบายที่ไม่ต้องอ่าน แล้วบอกจุดที่ควรฟังตรวจหลังสร้างเสียง ฉันจะส่งบทต่อจากนี้
```

## 6. เขียนบทอธิบายความรู้สำหรับผู้ฟังทั่วไป

```text
ฉันจะส่งเนื้อหาต้นฉบับในข้อความถัดไป ช่วยเรียบเรียงเป็นบทเสียงภาษาไทย 60–90 วินาทีสำหรับผู้ฟังทั่วไป ยึดเฉพาะข้อเท็จจริงที่ให้มา หากมีข้อขัดแย้งหรือข้อมูลไม่พอ ให้ถามก่อน ไม่สร้างคำแนะนำทางการแพทย์เฉพาะบุคคล ไม่ใช้ชื่อหรือข้อมูลผู้ป่วย ใช้ภาษาสุภาพ เข้าใจง่าย อธิบายศัพท์จำเป็นสั้น ๆ ส่งบทพร้อมอ่านโดยไม่มีหัวข้อ และแยกสไตล์เสียงสำหรับ Doctor Top CPD → สไตล์การพูด → กำหนดเอง เป็นภาษาอังกฤษสั้น ๆ โทนชัดเจน ใจเย็น เป็นกันเอง ไม่รับประกันเวลาตรงเป๊ะ ฉันจะตรวจความถูกต้องก่อนสร้างและเผยแพร่
```
